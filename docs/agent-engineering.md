# Agent engineering workflow guide

Scope: this repository (branch `accountability-layer`). Package-level rules apply
within their directories. Purpose: find the current project authorities and record
the setup decisions. This guide grants no permissions, proves no check passed, and
replaces no standard. Where a source below conflicts with this guide, the source wins.
